Qué es un programa y qué es Python

Una computadora no entiende frases como «avísame cuando llegue el correo». Solo sabe cumplir instrucciones muy pequeñas y exactas. Un programa es una lista de esas instrucciones, escrita en un orden concreto, para que la computadora haga una tarea. Las aplicaciones del celular, los videojuegos y las páginas web son programas, solo que muy grandes.

Un programa se parece a una receta de cocina: una lista de pasos que se cumplen en orden. La diferencia está en quien la sigue. Una persona entiende «una pizca de sal» y decide cuánta es. La computadora hace exactamente lo que está escrito, ni más ni menos, y no adivina lo que quisiste decir. Por eso en programación importa tanto escribir con precisión.

Las instrucciones se escriben en un lenguaje de programación: un idioma con reglas muy estrictas que una computadora puede interpretar. Existen cientos. Tú vas a empezar con Python, creado por Guido van Rossum y publicado por primera vez en 1991. Se eligió para empezar porque se lee casi como una frase en inglés y deja concentrarte en pensar el problema en vez de pelear con símbolos raros. Más adelante en el curso aprenderás otros lenguajes; lo que entiendas aquí te servirá en todos.

Python se usa en muchos campos: análisis de datos, inteligencia artificial, automatización de tareas, servidores y también videojuegos pequeños. No es el único lenguaje que necesitarás para crear apps y juegos completos, y por eso este curso te llevará por varios. Pero es una base excelente.

Cómo se ejecuta un programa en Python

Cuando instalas Python no instalas solo «un idioma»: instalas un programa llamado intérprete. El intérprete lee tu archivo de instrucciones, de arriba hacia abajo, y cumple cada línea en cuanto la lee. A cumplir las instrucciones se le llama ejecutar el programa. Mira cómo trabaja con un programa de tres líneas. Cada línea usa print, una orden que muestra un texto en pantalla (la verás en detalle en un momento).

Un programa se ejecuta de arriba hacia abajo, una línea después de otra. Si cambias el orden de las líneas, cambias lo que hace el programa. Esta regla vale para casi todo lo que programarás en el curso.

Prueba tú. Antes de pulsar «Ejecutar», predice en qué orden van a aparecer los tres mensajes. Después cambia el orden de las líneas y vuelve a ejecutar.

La terminal: hablar con tu computadora por escrito

Normalmente le das órdenes a la computadora con el mouse: abres carpetas, haces clic en botones. Los programadores también usan otra forma, escrita: la terminal (en inglés, terminal o console). Es una ventana donde escribes una orden, pulsas Enter y la computadora responde con texto. Cada orden se llama comando.

La necesitas por una razón práctica: así se ejecuta un programa de Python. También se usa para instalar herramientas y para casi todo el trabajo profesional con código, así que conviene perderle el miedo desde ahora.

macOSPulsa Cmd + Espacio, escribe Terminal y pulsa Enter.
LinuxBusca «Terminal» en el menú de aplicaciones. En muchas distribuciones se abre también con Ctrl + Alt + T.

La línea donde esperas escribir se llama prompt (en inglés, «indicación»). A veces muestra tu nombre de usuario y la carpeta donde estás. En esta página la representamos con el símbolo $; tú no lo escribes, es solo la marca de que ahí empieza un comando.

Cinco comandos para moverte

La terminal siempre está «dentro» de una carpeta (también llamada directorio): el lugar de tu computadora donde están guardados archivos y otras carpetas. Para trabajar necesitas saber en cuál estás y cómo cambiarla. Estos cinco comandos funcionan igual en PowerShell, macOS y Linux:

ComandoQué hace
pwdMuestra en qué carpeta estás ahora.
lsLista lo que hay dentro de la carpeta actual.
mkdir nombreCrea una carpeta nueva llamada nombre.
cd nombreEntra a la carpeta nombre.
cd ..Sube a la carpeta que contiene a la actual (los dos puntos significan «la de arriba»).

Así se ve una sesión corta. Lo que escribes va después del $; la respuesta de la computadora está en otro color:

$ pwd
/home/ana
$ mkdir mis-programas
$ ls
mis-programas
$ cd mis-programas
$ pwd
/home/ana/mis-programas

En Windows la ruta se ve distinta (por ejemplo C:\Users\Ana\mis-programas, con barras inclinadas hacia el otro lado), pero los comandos son los mismos. Existe otra terminal más antigua en Windows, el «Símbolo del sistema», que usa dir en lugar de ls. Usa PowerShell para que todo coincida con lo que lees aquí.

Una terminal obedece sin preguntar. Un comando mal escrito no rompe nada: solo devuelve un mensaje de error. Los comandos de borrado (rm, del) sí pueden eliminar archivos sin pasar por la papelera. No los usamos en esta estación, y cuando llegue el momento te avisaremos.

Practica en esta terminal de práctica, que no toca tu computadora. La misión: crea una carpeta llamada mis-programas y entra en ella. Escribe help si necesitas ver los comandos disponibles.

Instalar Python

Instala la versión de Python que python.org/downloads marque como la más reciente. Para este curso sirve cualquier versión 3.12 o posterior. Los números significan «versión mayor punto versión menor»: Python 3.14 es una versión mayor 3, menor 14. Siempre descarga desde la página oficial, nunca desde enlaces que te lleguen en anuncios o mensajes.

En Windows

Windows no trae Python. La documentación oficial recomienda instalarlo con el Python install manager, una herramienta pequeña que instala y actualiza Python por ti. Hay dos caminos equivalentes (según la documentación, las dos versiones son idénticas):

  1. Con la tienda de Windows: abre Microsoft Store, busca «Python Install Manager» y pulsa «Instalar».

  2. O desde la web: entra a python.org/downloads, descarga el Python install manager y ábrelo con doble clic.

  3. Abre PowerShell y escribe python --version. Si todavía no hay ninguna versión de Python instalada, el administrador instala la más reciente automáticamente la primera vez que usas el comando python. Puede preguntarte antes; acepta.

  4. Si te ofrece agregar una carpeta al PATH (la lista de lugares donde Windows busca los programas que escribes en la terminal), es opcional: con el comando py también puedes ejecutar Python.

En macOS

  1. Entra a python.org/downloads y descarga el instalador para macOS: un archivo con extensión .pkg.

  2. Ábrelo con doble clic. Pulsa «Continuar», acepta la licencia y pulsa «Instalar». El sistema te pedirá tu contraseña.

  3. Abre la Terminal y escribe python3 --version.

En Linux

La mayoría de las distribuciones ya incluyen Python. Compruébalo primero en la terminal con python3 --version. Si el comando no existe, instálalo con el gestor de paquetes de tu distribución. En Ubuntu y Debian es:

$ sudo apt install python3

sudo significa «ejecuta esto con permisos de administrador» y te pedirá tu contraseña. En otras distribuciones el comando cambia (por ejemplo, sudo dnf install python3 en Fedora).

Comprobar que funciona

En cualquier sistema, el comando --version pregunta qué versión hay instalada. Si ves un número de versión, Python está listo:

SistemaComandoDebe responder algo como
Windowspython --versionPython 3.14.x
macOS y Linuxpython3 --versionPython 3.14.x

El número exacto después de «Python» será el de la versión que instalaste; lo importante es que empiece con 3.

En Windows el comando es python. En macOS y Linux es python3, porque en esos sistemas el nombre python a veces apunta a una versión antigua (la 2, que ya no se usa). Cuando este curso escriba python en un comando de terminal y tú uses macOS o Linux, escribe python3.

Si la terminal dice que no encuentra python, lo más común es que abriste la terminal antes de instalar. Ciérrala, ábrela de nuevo y vuelve a probar. Si sigue igual en Windows, la guía oficial tiene una sección de problemas frecuentes: Usar Python en Windows.

Las instrucciones de instalación cambian con el tiempo. Si algún paso de esta página no coincide con lo que ves en tu pantalla, la documentación oficial de Python es la fuente que manda.

Un editor para escribir código

El código es texto simple: letras, números y símbolos, sin colores ni tamaños. Por eso no sirve un procesador de textos como Word, que guarda además información de formato que Python no entiende. Se usa un editor de código: un programa para escribir texto simple que además colorea las palabras según su función, sugiere lo que vas a escribir y marca errores a medida que tecleas.

Vamos a usar Visual Studio Code (abreviado «VS Code»), un editor gratuito de Microsoft que usan millones de programadores. Descárgalo desde code.visualstudio.com e instálalo como cualquier programa. VS Code se actualiza con frecuencia y sus menús cambian de lugar de vez en cuando, así que aquí describimos las zonas con un dibujo y no con capturas de pantalla.

  1. Explorador: la lista de archivos y carpetas del proyecto en el que trabajas.
  2. Editor: donde escribes el código. Cada archivo abierto tiene su pestaña.
  3. Terminal: la misma terminal que ya conoces, dentro del editor, ya situada en la carpeta de tu proyecto.
  4. Botón de ejecutar: el triángulo de la esquina; ejecuta el archivo abierto. Lo usarás más adelante; hoy ejecutas desde la terminal para entender qué pasa.

Instalar la extensión de Python

Una extensión es un complemento que añade funciones al editor. La de Python, publicada por Microsoft, le enseña a VS Code a entender Python: lo colorea bien, sugiere código y avisa de errores.

  1. Abre VS Code y pulsa el icono de Extensiones en la barra de la izquierda (parece cuatro cuadrados). También funciona Ctrl + Shift + X (Cmd + Shift + X en macOS).

  2. Escribe Python en el buscador. Elige la que dice «Microsoft» como publicador (su identificador es ms-python.python) y pulsa «Instalar».

  3. Si VS Code te pregunta qué intérprete usar, elige el Python que instalaste en la sección anterior.

En el buscador de extensiones hay muchas con nombres parecidos. Comprueba siempre el nombre del publicador (Microsoft) antes de instalar. Instalar una extensión de un desconocido es dar permiso a código ajeno para ejecutarse en tu computadora.

Tu carpeta de trabajo

  1. En la terminal, crea la carpeta mis-programas y entra en ella, como practicaste. Puedes hacerlo también con el mouse; lo importante es que exista.

  2. En VS Code, abre el menú «Archivo», elige «Abrir carpeta» y selecciona mis-programas.

  3. En el Explorador, pulsa el icono de «Nuevo archivo» y llámalo hola.py.

La parte .py es la extensión del archivo: las letras después del punto, que indican qué tipo de archivo es. Los programas de Python terminan en .py. Si en Windows no ves las extensiones en el Explorador de archivos, se activan en el menú «Ver», opción «Mostrar», «Extensiones de nombre de archivo».

Tu primer programa: Hola, mundo

Tradicionalmente, el primer programa que se escribe en cualquier lenguaje muestra el mensaje «Hola, mundo». Sirve para comprobar que todo está bien instalado. En hola.py escribe esta única línea:

print("Hola, mundo")

Guarda el archivo con Ctrl + S (Cmd + S en macOS). Un programa sin guardar no se ejecuta: Python lee el archivo del disco, no lo que ves en pantalla.

Ahora abre la terminal de VS Code con el menú «Terminal» y la opción «Nueva terminal». Se abre en la parte de abajo, ya dentro de tu carpeta. Escribe el comando que ejecuta el archivo:

$ python hola.py
Hola, mundo

En macOS y Linux escribe python3 hola.py. Si apareció «Hola, mundo», acabas de programar: escribiste instrucciones y la computadora las cumplió. Esto es lo que pasó por dentro:

Qué significa cada parte de la línea

print es una función: una instrucción ya preparada que alguien escribió antes y que tiene un nombre para poder usarla. print significa «imprimir» y su trabajo es mostrar algo en la consola. Usar una función se llama llamarla, y se hace escribiendo su nombre seguido de paréntesis. Dentro de los paréntesis va lo que le entregas a la función, en este caso, lo que debe mostrar.

Lo que va entre comillas, "Hola, mundo", es una cadena de texto (en inglés, string): un dato que es texto. Las comillas le dicen a Python «esto es un texto, no una orden». Pueden ser dobles "..." o simples '...', pero tienen que cerrarse con las mismas con las que abrieron. Las comillas no se muestran: solo se muestra lo de adentro.

Mira la diferencia entre un texto y un cálculo. Predice qué mostrará cada línea antes de ejecutar:

La primera línea no lleva comillas, así que Python calcula la suma y muestra 10. La segunda sí las lleva, así que es un texto y se muestra tal cual. La tercera y la cuarta entregan varios datos a print, separados por comas: los muestra todos en la misma línea, con un espacio en medio.

Dentro de un texto puedes escribir tildes, ñ, signos de apertura (¿ ¡) y emojis sin problema. Python guarda el texto con un sistema llamado Unicode que incluye los caracteres de casi todos los idiomas.

Si al ejecutar aparece can't open file ... [Errno 2] No such file or directory, la terminal no encuentra el archivo. Casi siempre es porque la terminal está en otra carpeta o porque escribiste mal el nombre. Usa pwd para ver dónde estás y ls para ver si hola.py aparece en la lista.

Comentarios: notas para personas

Un comentario es una nota que escribes dentro del programa para las personas que lo lean, incluido tu yo del futuro. Python ignora todo lo que va después del símbolo # en esa línea.

# Este programa saluda a todo el mundo
print("Hola, mundo")   # esta nota va al final de la línea

Úsalos para explicar el porqué de algo que no se entiende solo, no para repetir lo que ya dice el código. Un comentario como # muestra hola encima de print("hola") no aporta nada. Los comentarios también sirven para desactivar una línea sin borrarla: si la empiezas con #, Python la salta.

Cuando algo falla: leer los errores

Vas a equivocarte, y no es una señal de que lo haces mal: todo programador, también el más experimentado, ve errores todos los días. Lo que cambia con la experiencia es que aprendes a leerlos. Un mensaje de error de Python es una pista bastante precisa sobre qué salió mal y dónde.

Vamos a provocar un error a propósito. En este programa la palabra print está escrita con mayúscula inicial:

Print("Hola, mundo")

Al ejecutarlo en la terminal, Python responde con esto:

Traceback (most recent call last):
  File "/home/ana/mis-programas/hola.py", line 1, in <module>
    Print("Hola, mundo")
    ^^^^^
NameError: name 'Print' is not defined. Did you mean: 'print'?

A este bloque se le llama traceback (en inglés, «rastro hacia atrás»): el recorrido que hizo Python hasta llegar al problema. Léelo así:

Aquí el mensaje dice NameError: «el nombre Print no está definido», es decir, Python no conoce nada con ese nombre. Además adivina lo que quisiste escribir: Did you mean: 'print'? («¿quisiste decir print?»). Python distingue mayúsculas de minúsculas, así que print y Print son nombres distintos.

Lee un error de abajo hacia arriba. La última línea te dice qué pasó; la línea de código con las marcas ^ te dice dónde. Si no entiendes el mensaje, copia su última línea y búscala en internet: casi seguro a alguien más le pasó antes que a ti.

Los errores de sintaxis se detectan antes de ejecutar nada: Python revisa que todo el archivo esté bien escrito y solo entonces empieza a cumplir las líneas. Por eso, si una de las líneas tiene un error de sintaxis, no se ejecuta ni siquiera la primera. Los demás errores, como NameError, aparecen cuando el programa llega a esa línea; las anteriores ya se cumplieron.

El texto exacto de los mensajes puede cambiar un poco entre versiones de Python, y el que ves en el navegador en esta página puede ser distinto al que te muestra tu terminal. La estructura (dónde, qué palabra, qué pasó) es siempre la misma.

Variables: guardar datos con nombre

Un programa que solo muestra mensajes fijos sirve de poco. Casi todo programa necesita recordar datos: el nombre de quien juega, los puntos acumulados, el precio de un producto. Para eso existen las variables: un nombre que le das a un dato para poder usarlo después.

En Python se crea una variable escribiendo el nombre, el signo = y el dato:

nombre = "Ana"
edad = 25
print(nombre)
print(edad)

Esa operación se llama asignación: «guarda el dato de la derecha bajo el nombre de la izquierda». En Python no hace falta ninguna palabra especial para crear una variable: la primera vez que le asignas un valor, existe.

Imagina una etiqueta adhesiva con un nombre escrito, pegada sobre una caja que contiene un dato. Si más tarde pegas la etiqueta en otra caja, el nombre pasa a señalar el nuevo dato. El límite de la analogía: la computadora no «vacía» la caja vieja al instante; nadie la señala ya, y la descartará cuando necesite el espacio.

En programación, = no significa «es igual a». Significa «guarda lo de la derecha bajo el nombre de la izquierda». Por eso puntos = puntos + 10 tiene sentido: Python calcula primero la derecha (el valor actual de puntos más 10) y guarda el resultado otra vez en puntos.

Sigue este programa línea por línea. Fíjate en cómo cada línea usa lo que las anteriores guardaron:

precio = 120
cantidad = 3
total = precio * cantidad
print("Total:", total)

Cómo elegir nombres

Python es estricto con los nombres de variables. Un nombre válido:

  • Puede tener letras, números y guion bajo (_), pero no puede empezar con un número: jugador2 sí, 2jugador no.
  • No puede tener espacios ni guiones medios: mi nombre y mi-nombre dan error.
  • No puede ser una palabra reservada del lenguaje, como if, for o True.
  • Distingue mayúsculas de minúsculas: edad, Edad y EDAD son tres variables distintas.

Por convención, en Python los nombres de varias palabras se escriben en minúsculas y unidas con guion bajo: puntos_totales, nombre_de_usuario. Esta forma se llama snake_case («caso serpiente»). La guía de estilo oficial de Python, llamada PEP 8, la recomienda.

Difícil de entender

x = 1500
x2 = 0.16
t = x + x * x2

Se entiende solo

precio = 1500
tasa_impuesto = 0.16
precio_final = precio + precio * tasa_impuesto

Los dos programas hacen exactamente lo mismo. La computadora trabaja igual con x, pero tú, dentro de tres meses, no vas a recordar qué era x. Los nombres son para las personas.

Python te deja escribir print = 5, pero entonces la función print deja de funcionar en ese programa, porque el nombre ahora señala al 5. Evita nombres que ya significan algo en Python.

Una pregunta sutil, muy frecuente: ¿qué pasa cuando una variable se copia en otra? Resuélvela en el siguiente taller antes de leer la explicación.

Muestra 9 y luego 5. La línea b = a toma el dato que a tiene en ese momento (5) y lo asocia también a b. Cuando después cambias a, b sigue con el 5 que ya tenía. Cambiar una variable no cambia a las demás.

Mensajes que mezclan texto y variables

Casi siempre querrás mostrar un mensaje que combine texto fijo con datos de variables, como «Hola, Ana. Tienes 25 años». Hay dos maneras cómodas de hacerlo.

La primera ya la usaste: entregar varios datos a print, separados por comas. Python los muestra en una línea con un espacio entre cada uno.

nombre = "Ana"
edad = 25
print("Hola,", nombre, "- tienes", edad, "años")

La segunda se llama f-string (por formatted string, «texto con formato»). Escribes una f pegada antes de la comilla de apertura y, dentro del texto, pones entre llaves {} el nombre de la variable que quieres insertar:

nombre = "Ana"
edad = 25
print(f"Hola, {nombre}. Tienes {edad} años.")

Se muestra Hola, Ana. Tienes 25 años. Python reemplaza cada {...} por el valor de la variable. Dentro de las llaves también puedes hacer cálculos: {edad + 1} mostraría 26. Esta forma suele ser más fácil de leer, y es la que más verás en código real.

Si intentas unir un texto y un número con el signo +, como en print("Edad: " + 25), Python responde: TypeError: can only concatenate str (not "int") to str. Dice que solo sabe unir texto con texto. Por ahora usa comas o f-strings, que no tienen ese problema. En la siguiente estación verás por qué ocurre y cómo convertir entre tipos de datos.

Pedir datos a quien usa el programa

Hasta ahora todo lo que sabe tu programa lo escribiste tú en el archivo. La función input() hace que el programa se detenga, muestre una pregunta y espere a que la persona escriba una respuesta y pulse Enter. Lo que escriba se puede guardar en una variable.

nombre = input("¿Cómo te llamas? ")
print(f"Hola, {nombre}. Ya estás programando.")

Guarda ese código como saludo.py y ejecútalo en tu terminal. Esto verás (lo que escribes tú va después de la pregunta):

$ python saludo.py
¿Cómo te llamas? Ana
Hola, Ana. Ya estás programando.

Los ejercicios de esta página se ejecutan en el navegador y no pueden detenerse a esperar lo que escribas, así que no usan input(). Pruébalo en tu terminal.

input() siempre entrega texto, aunque la persona escriba un número. Si escribe 25, tu variable contiene el texto "25", con el que no se puede hacer matemática todavía. En la próxima estación aprenderás a convertirlo en número.

Resumen: lo que te llevas

  • Un programa es una lista de instrucciones que la computadora cumple de arriba hacia abajo, en el orden en que las escribiste.
  • El intérprete de Python lee tu archivo .py y ejecuta cada línea. Lo ejecutas desde la terminal con python archivo.py (en macOS y Linux, python3).
  • La terminal se maneja con comandos. Para moverte te bastan pwd, ls, mkdir y cd.
  • El código se escribe en un editor de código como VS Code, no en un procesador de textos, y se guarda antes de ejecutarlo.
  • print() muestra datos en la consola. Lo que va entre comillas es texto; lo que no, Python lo calcula o lo busca como nombre.
  • Un comentario empieza con #, es solo para personas y Python lo ignora.
  • Un mensaje de error se lee de abajo hacia arriba: la última línea dice qué pasó y la línea con ^ señala dónde.
  • Una variable es un nombre para un dato. Se crea con =, se puede cambiar, y sus nombres van en minúsculas con guion bajo (puntos_totales).
  • Las f-strings (f"Hola, {nombre}") insertan variables dentro de un texto.
  • input() pide un dato a la persona, y siempre lo entrega como texto.

Práctica

Los ejercicios van de menos a más difíciles. En los primeros casi todo está hecho; en los últimos tendrás que decidir tú. Si te atascas, abre las pistas una por una antes de mirar la solución. Equivocarte y volver a intentar también es practicar.

Tu primer print

Escribe un programa que muestre exactamente: Hola, mundo

Pista 1

La función que muestra texto se llama print y lleva paréntesis.

Pista 2

El texto va entre comillas dentro de los paréntesis: print("...").

Ver una solución 
print("Hola, mundo")

También funciona con comillas simples: print('Hola, mundo').

Tres mensajes en orden

La primera línea ya está escrita. Agrega las otras dos para que el programa muestre, una debajo de la otra: Buenos días, Soy Python y Hasta pronto.

Pista 1

Cada mensaje necesita su propio print, en su propia línea.

Pista 2

El orden de las líneas es el orden de los mensajes en la consola.

Ver una solución 
print("Buenos días")
print("Soy Python")
print("Hasta pronto")

Arregla el programa

Este programa tiene dos errores y no muestra nada. Corrígelos para que muestre Hola, mundo y debajo Adiós.

Pista 1

Una de las líneas tiene una letra en mayúscula que no debería estar. Python distingue mayúsculas de minúsculas.

Pista 2

La otra línea abre unas comillas y no las cierra. Recuerda que Python revisa la sintaxis de todo el archivo antes de ejecutar la primera línea. En el navegador, el mensaje puede hablar del paréntesis que «nunca se cerró»: es el mismo problema, porque las comillas sin cerrar se tragan el paréntesis.

Ver una solución 
print("Hola, mundo")
print("Adiós")

Mientras la segunda línea tuviera las comillas sin cerrar, ni siquiera la primera se ejecutaba: el error de sintaxis se detecta antes de empezar.

Ordena el programa

Las líneas de este programa están desordenadas. Ordénalas para que primero se creen las variables y después se muestren. Pista: no puedes usar una variable antes de crearla.

  1. nombre = "Ana"
  2. ciudad = "Quito"
  3. print("Me llamo", nombre)
  4. print("Vivo en", ciudad)
Pista

Si print(nombre) va antes de nombre = "Ana", Python lanza un NameError: todavía no sabe qué es nombre.

Una variable, dos mensajes

Crea una variable llamada ciudad con el texto "Lima". Después muestra dos líneas: Vivo en Lima y Me encanta Lima. La palabra Lima debe aparecer una sola vez en tu código, en la variable; en los print usa el nombre ciudad.

Pista 1

Un print puede recibir un texto y una variable separados por coma: print("Vivo en", ciudad).

Pista 2

Si cambiaras el valor de ciudad en la primera línea, los dos mensajes cambiarían solos. Esa es la ventaja de usar una variable.

Ver una solución 
ciudad = "Lima"
print("Vivo en", ciudad)
print("Me encanta", ciudad)

Con una f-string también vale: print(f"Vivo en {ciudad}").

Total de una compra

Una persona compra 4 cuadernos de 250 pesos cada uno. Las variables ya existen. Calcula el total en una tercera variable y muestra Total: 1000.

Pista 1

Multiplicar se escribe con asterisco: precio * cantidad. Guarda el resultado en una variable nueva.

Pista 2

Con print("Total:", total) el resultado sale separado por un espacio, justo como se pide.

Ver una solución 
precio = 250
cantidad = 4
total = precio * cantidad
print("Total:", total)

Una frase con f-string

Usa una f-string para mostrar Ana trabaja como diseñadora tomando los datos de las dos variables.

Pista 1

La estructura es print(f"... {variable} ..."). Las llaves van dentro de las comillas.

Pista 2

Necesitas dos pares de llaves: uno para nombre y otro para oficio.

Ver una solución 
nombre = "Ana"
oficio = "diseñadora"
print(f"{nombre} trabaja como {oficio}")

Marcador de un juego

La variable puntos empieza en 0. Suma 10 puntos y muestra el marcador. Después suma 5 más y vuelve a mostrarlo. La consola debe mostrar 10 y debajo 15. Para sumar, actualiza la propia variable con puntos = puntos + ....

Pista 1

Necesitas dos veces el mismo patrón: sumar con puntos = puntos + ... y mostrar con print(puntos).

Pista 2

La segunda suma parte de lo que ya vale puntos (10), no de cero. Por eso el resultado final es 15 y no 5.

Ver una solución 
puntos = 0
puntos = puntos + 10
print(puntos)
puntos = puntos + 5
print(puntos)

Intercambia dos valores

Las variables a y b guardan dos colores. Intercambia sus valores para que a tenga el de b y viceversa, sin escribir los nombres de los colores otra vez. Al final, el programa debe mostrar azul y debajo rojo. Ayuda: si haces a = b directamente, el primer color se pierde.

Pista 1

Piensa en dos vasos con líquidos distintos que quieres intercambiar: necesitas un tercer vaso vacío para ir pasando uno.

Pista 2

Primero guarda el valor de a en una variable auxiliar. Luego pasa b a a. Por último, pasa el auxiliar a b.

Ver una solución 
a = "rojo"
b = "azul"
auxiliar = a
a = b
b = auxiliar
print(a)
print(b)

Python también permite intercambiar en una sola línea (a, b = b, a), pero esa forma usa conceptos que verás más adelante. Es bueno entender primero el truco del tercer vaso.

Proyecto: tu tarjeta de presentación

Vas a crear un programa que muestre una tarjeta con tus datos. Es corto, pero es un programa de verdad: lo guardarás en tu computadora y lo ejecutarás desde la terminal. Es el primero de los proyectos pequeños que, más adelante, se combinarán en el proyecto final del curso.

La tarjeta debe tener cinco líneas: un borde de signos =, tres líneas de datos (nombre, ciudad y un pasatiempo) y otro borde igual. Por ejemplo:

==============================
Nombre: Ana
Ciudad: Quito
Pasatiempo: dibujar
==============================

  1. Planea. En un papel escribe qué tres datos mostrarás. Cada dato será una variable.

  2. Crea las variables nombre, ciudad y pasatiempo, con tus datos.

  3. Muestra el borde. Un texto se puede multiplicar por un número para repetirlo: "=" * 30 da treinta signos igual seguidos. Usa print("=" * 30).

  4. Muestra cada dato con una f-string, por ejemplo print(f"Nombre: {nombre}").

  5. Cierra con otro borde.

Escríbelo primero aquí. El verificador comprueba la forma de la tarjeta, no tus datos, así que pon los tuyos.

Ver una solución de referencia 
# Tarjeta de presentación
nombre = "Ana"
ciudad = "Quito"
pasatiempo = "dibujar"

print("=" * 30)
print(f"Nombre: {nombre}")
print(f"Ciudad: {ciudad}")
print(f"Pasatiempo: {pasatiempo}")
print("=" * 30)

Cambiar los datos de la tarjeta es cambiar solo las tres primeras líneas. El resto del programa no se toca. Eso es lo que logran las variables.

Llévalo a tu computadora

  1. Copia tu código a un archivo nuevo llamado tarjeta.py, dentro de mis-programas.

  2. Guárdalo con Ctrl + S y ejecútalo en la terminal con python tarjeta.py (o python3 tarjeta.py).

  3. Cambia tus datos, guarda y ejecuta otra vez. Verifica que la tarjeta cambió.

Si quieres ir más lejos

  • Agrega una cuarta línea, por ejemplo «Comida favorita».
  • En tu computadora, reemplaza los datos fijos por input() para que cualquier persona cree su propia tarjeta al ejecutar el programa.
  • Cambia el borde por otro símbolo ("*" o "-") y otra longitud.

Autoevaluación

Responde sin mirar la estación. Después de elegir una opción verás por qué es correcta o por qué no.

¿Qué es un programa?

  1. Una aplicación que se descarga de internet.

    Una aplicación es un tipo de programa, pero no todos los programas se descargan.

  2. Una lista de instrucciones que la computadora cumple en orden.

    Correcto. Esa es la definición, y por eso el orden de las líneas importa.

  3. Un archivo de texto con información.

    Un archivo de texto guarda información, pero no da órdenes a la computadora.

  4. Un lenguaje como Python.

    Python es un lenguaje para escribir programas, no el programa en sí.

Estás en la terminal y escribes cd mis-programas. ¿Qué ocurre?

  1. Se crea una carpeta llamada mis-programas.

    Crear una carpeta es trabajo de mkdir.

  2. Se muestra lo que hay dentro de mis-programas.

    Mostrar el contenido es trabajo de ls.

  3. La terminal entra a la carpeta mis-programas, que ya existía.

    Correcto. cd cambia la carpeta donde estás parado. Si la carpeta no existe, la terminal responde con un error.

  4. Se borra la carpeta mis-programas.

    Ningún comando de esta estación borra. cd solo cambia de lugar.

En macOS quieres comprobar que Python quedó instalado. ¿Qué escribes en la terminal?

  1. python3 --version

    Correcto. En macOS y Linux el comando se llama python3. Si responde con un número que empieza con 3, está listo.

  2. python --install

    Esa opción no existe. --version es la que pregunta la versión.

  3. version python

    El orden está al revés: primero va el nombre del programa y después la opción.

  4. ls python

    ls lista archivos; no pregunta si Python está instalado.

¿Por qué no se escribe código en un procesador de textos como Word?

  1. Porque Word es de pago.

    El precio no es el motivo. Un editor de pago también sería un mal lugar para guardar código.

  2. Porque Word no tiene teclas para los paréntesis.

    Word tiene todas las teclas. El problema es otro.

  3. Porque Python solo lee archivos que se crean en VS Code.

    Python lee cualquier archivo de texto simple con extensión .py, sin importar con qué se escribió.

  4. Porque guarda información de formato y a veces cambia las comillas, y el código debe ser texto simple.

    Correcto. Un editor de código guarda solo texto simple y además colorea y sugiere.

Un programa tiene tres líneas con print. ¿En qué orden las cumple Python?

  1. En orden alfabético, según el texto que muestran.

    Python no ordena nada alfabéticamente.

  2. De arriba hacia abajo, en el orden en que están escritas.

    Correcto. Una línea después de otra, sin saltar ni adelantarse.

  3. Primero la última y al final la primera.

    Es al revés: empieza por la primera.

  4. Todas a la vez.

    El intérprete cumple una instrucción por vez, en orden.

Escribes print("Hola) y Python responde con un error que menciona «unterminated string literal». ¿Qué falta?

  1. Un punto y coma al final.

    Python no necesita punto y coma al final de las líneas.

  2. Importar la función print.

    print ya viene incluida en Python.

  3. Cerrar las comillas del texto.

    Correcto. El texto abrió comillas y nunca las cerró. Es un SyntaxError.

  4. Escribir print con mayúscula.

    Con mayúscula daría un NameError, no este.

Escribes Print("Hola") y aparece NameError: name 'Print' is not defined. ¿Cuál es la causa?

  1. Python distingue mayúsculas de minúsculas y el nombre correcto es print.

    Correcto. Print y print son nombres distintos para Python, y solo el segundo existe.

  2. Falta guardar el archivo.

    Si no hubieras guardado, correría la versión anterior, sin este error.

  3. Faltan las comillas dentro de los paréntesis.

    Las comillas están. El problema es el nombre de la función.

  4. La terminal está en otra carpeta.

    Eso daría «No such file or directory», porque ni siquiera encontraría el archivo.

Después de ejecutar edad = 25 y luego edad = 26, ¿qué ocurre con la variable?

  1. Python da un error porque edad ya existía.

    Volver a asignar es normal y no da error.

  2. La variable guarda los dos valores, 25 y 26.

    Una variable tiene un solo dato en cada momento.

  3. Se suman: la variable vale 51.

    El signo = asigna; no suma lo que había.

  4. El nombre edad pasa a señalar el dato 26.

    Correcto. La etiqueta se despega del 25 y se pega al 26.

¿Cuál de estos es un nombre de variable válido en Python?

  1. 2jugador

    No puede empezar con un número.

  2. mi_nombre

    Correcto. Letras y guion bajo, sin espacios y sin empezar con número.

  3. mi nombre

    Los espacios no están permitidos.

  4. for

    Es una palabra reservada del lenguaje; no puede usarse como nombre.

Se ejecuta este código. ¿Qué muestra?
a = 5
b = a
a = 9
print(b)

  1. 9

    Eso sería si b siguiera a a. No lo hace: b = a toma el dato de ese momento.

  2. 14

    Python no suma las variables por sí solo.

  3. 5

    Correcto. b tomó el 5 cuando se escribió b = a. Cambiar a después no cambia a b.

  4. Un error, porque a cambió.

    Cambiar el valor de una variable es normal y no da error.

La persona escribe 25 cuando input() se lo pide. ¿Qué tipo de dato recibe tu variable?

  1. Texto ("25").

    Correcto. input() siempre entrega texto. Con él todavía no se puede hacer matemática.

  2. El número 25.

    Para tener el número habría que convertirlo, y eso lo verás en la próxima estación.

  3. Un número, pero solo si es entero.

    No importa si es entero o decimal: siempre llega como texto.

  4. Ninguno hasta que uses print.

    El dato queda guardado desde que la persona pulsa Enter.

¿Qué muestra print(f"Total: {2 * 3}")?

  1. Total: {2 * 3}

    Eso pasaría sin la f antes de las comillas. Con la f, las llaves se calculan.

  2. Total: 2 * 3

    Las llaves no se muestran: se reemplazan por su resultado.

  3. Un error, porque no hay variables.

    Dentro de las llaves puedes poner cualquier cálculo, no solo variables.

  4. Total: 6

    Correcto. Python calcula lo que hay dentro de las llaves e inserta el resultado.

Glosario

Programa
Lista de instrucciones que una computadora cumple en orden para hacer una tarea.
Lenguaje de programación
Idioma con reglas estrictas en el que se escriben las instrucciones de un programa.
Python
Lenguaje de programación creado por Guido van Rossum, publicado en 1991. Se lee casi como una frase y se usa en muchos campos.
Intérprete
Programa que lee tu código línea por línea y lo ejecuta. Al instalar Python se instala su intérprete.
Ejecutar
Hacer que la computadora cumpla las instrucciones de un programa.
Terminal
Ventana donde das órdenes a la computadora escribiéndolas. También se llama consola.
Comando
Orden escrita que le das a la terminal, como ls o cd.
Prompt
La marca que muestra la terminal para indicar que espera un comando. En esta página se representa con $.
Carpeta (directorio)
Lugar de la computadora donde se guardan archivos y otras carpetas.
Editor de código
Programa para escribir texto simple que además colorea el código y ayuda a escribirlo. Visual Studio Code es uno.
Extensión de archivo
Las letras después del punto en el nombre de un archivo, que indican su tipo. Los programas de Python terminan en .py.
Extensión de VS Code
Complemento que añade funciones al editor, como entender Python.
Función
Instrucción ya preparada, con nombre, que puedes usar escribiendo su nombre y paréntesis. print es una.
Cadena de texto (string)
Dato que es texto. En Python se escribe entre comillas.
Variable
Nombre que le das a un dato para poder usarlo después. Se crea con =.
Asignación
Guardar un dato bajo el nombre de una variable, con el signo =.
Comentario
Nota para personas dentro del código. En Python empieza con # y el intérprete la ignora.
Error de sintaxis (SyntaxError)
Error que aparece cuando una línea rompe las reglas de escritura del lenguaje, como unas comillas sin cerrar. Se detecta antes de ejecutar.
NameError
Error que aparece cuando usas un nombre que Python no conoce: una variable o función mal escrita o sin crear.
Traceback
Mensaje de error de Python que muestra el recorrido hasta el problema: el archivo, la línea y qué pasó.
Sangría (indentación)
Espacios al principio de una línea. En Python tienen significado, por eso una sangría de más da error.
f-string
Texto con una f antes de las comillas que permite insertar variables o cálculos entre llaves {}.
input()
Función que pausa el programa, muestra una pregunta y devuelve como texto lo que la persona escribe.
