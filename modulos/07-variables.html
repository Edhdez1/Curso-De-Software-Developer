Lo que vas a lograr

Un programa trabaja con datos: el nombre de quien juega, el precio de un producto, los segundos que quedan en una partida. Para usar esos datos necesitas guardarlos con un nombre y poder cambiarlos. Eso es una variable, y es la pieza con la que se construye todo lo demás.

  • Crear variables con let y constantes con const, y saber cuándo usar cada una.
  • Elegir nombres de variables válidos y fáciles de entender.
  • Reconocer los tipos de datos básicos: números, textos, booleanos, undefined y null.
  • Hacer cálculos con los operadores aritméticos, incluido el resto (%).
  • Unir textos y crear mensajes con plantillas literales (`Hola, ${nombre}`).
  • Predecir qué pasa cuando mezclas tipos (por qué "5" + 3 da "53") y convertir un tipo en otro.
  • Escribir un programa corto que calcula y muestra resultados a partir de variables.

Antes de empezar

Necesitas saber escribir y ejecutar console.log(...). Si todavía no lo has hecho, pasa primero por la Estación 6: Tu primer programa. Todo lo demás lo vas a practicar aquí mismo, en el navegador.

Qué es una variable

Una variable es un nombre que le das a un dato para poder usarlo después. Cuando escribes let edad = 25; le estás diciendo a la computadora: «guarda el número 25 y, cuando yo diga edad, dame ese número».

Para entenderlo

Piensa en una etiqueta adhesiva con un nombre escrito. Pegas la etiqueta edad sobre el número 25. Si mañana cumples años, despegas la etiqueta y la pegas sobre el 26. La etiqueta es la variable; lo que está debajo es su valor.

Hay tres palabras que vas a usar todo el tiempo:

  • Declarar es crear la variable: let edad. Solo se hace una vez.
  • Asignar es darle un valor con el signo =: edad = 26. Se puede hacer muchas veces.
  • Inicializar es declarar y asignar a la vez: let edad = 25. Es lo más común.

Cuidado

En programación, = no significa «es igual a». Significa «guarda el valor de la derecha en la variable de la izquierda». Por eso puntos = puntos + 10 tiene sentido: toma el valor actual de puntos, súmale 10 y guarda el resultado otra vez en puntos. Para comparar si dos cosas son iguales se usa ===, que verás en la próxima estación.

let, const y cómo elegir nombres

JavaScript tiene dos formas modernas de crear variables:

Palabra¿Se puede reasignar?Úsala para…
constNoValores que no van a cambiar: el nombre de un jugador, la gravedad de tu juego, el precio del IVA.
letSíValores que cambian: la puntuación, la vida restante, un contador.
 
const gravedad = 9.8;    // no cambia en todo el juego
let vidas = 3;           // va a bajar cuando pierdas
vidas = vidas - 1;       // bien: vidas se creó con let
gravedad = 10;           // ERROR: no se puede reasignar una constante

Idea clave

Empieza siempre con const. Si más adelante descubres que necesitas cambiar el valor, cámbialo a let. Así, cuando alguien lea tu código, sabrá de un vistazo qué valores cambian y cuáles no.

¿Y var?

En código antiguo verás var edad = 25;. Es la forma que existía antes de 2015 y tiene comportamientos confusos que veremos en la Estación 10: Funciones. En código nuevo, no la uses.

Reglas para los nombres

JavaScript es estricto con los nombres de las variables. Un nombre:

  • Puede tener letras, números, _ y $, pero no puede empezar con un número: jugador2 sí, 2jugador no.
  • No puede tener espacios ni guiones: mi nombre y mi-nombre dan error.
  • No puede ser una palabra reservada del lenguaje, como let, const, if o function.
  • Distingue mayúsculas y minúsculas: edad, Edad y EDAD son tres variables distintas.

Cuando un nombre tiene varias palabras, en JavaScript se escriben juntas y cada palabra nueva empieza con mayúscula: precioTotal, vidaMaxima, nombreDeUsuario. Esto se llama camelCase, porque las mayúsculas parecen las jorobas de un camello.

Difícil de entender

let x = 1500;
let x2 = 0.16;
let t = x + x * x2;

Se entiende solo

const precio = 1500;
const tasaImpuesto = 0.16;
const precioFinal = precio + precio * tasaImpuesto;

Los dos programas hacen exactamente lo mismo. El segundo se lee como una frase. Los nombres son para las personas, no para la computadora: la computadora funciona igual con x, pero tú, dentro de tres meses, no vas a recordar qué era x.

Consejo de oficio

En los equipos profesionales se pasa mucho más tiempo leyendo código que escribiéndolo. Un buen nombre ahorra horas. Si te cuesta ponerle nombre a una variable, suele ser señal de que todavía no tienes claro qué representa.

Tipos de datos

No todos los datos son iguales. No es lo mismo el número 42 que el texto «42»: con el primero puedes hacer cuentas; el segundo es solo una secuencia de caracteres. A cada clase de dato se le llama tipo. Estos son los tipos básicos de JavaScript:

TipoQué representaEjemplos
numberNúmeros, enteros o con decimales42, -7, 3.14
stringTexto (en español, «cadena de caracteres»). Siempre entre comillas"Hola", 'Ana', "42"
booleanVerdadero o falso. Solo hay dos valorestrue, false
undefined«Todavía no tiene valor». Es lo que vale una variable declarada sin asignarlet x; → x vale undefined
null«Vacío a propósito». Lo pones tú para decir que no hay nadalet ganador = null;

Existen otros tipos (bigint para números gigantes y symbol para identificadores únicos) que casi no vas a necesitar al principio. Los objetos y las listas, que sirven para agrupar muchos datos, tienen su propia estación: la Estación 11: Colecciones.

Para saber de qué tipo es un valor, usa typeof:

console.log(typeof 42);        // "number"
console.log(typeof "42");      // "string"
console.log(typeof true);      // "boolean"
let sinValor;
console.log(typeof sinValor);  // "undefined"

Error común

Poner comillas a un número lo convierte en texto. "25" no es el número 25: es un texto con los caracteres 2 y 5. Si luego intentas sumarlo, vas a tener sorpresas (las verás en la sección Convertir entre tipos).

Una rareza histórica

typeof null devuelve "object", no "null". Es un error del lenguaje de 1995 que nunca se corrigió para no romper los millones de páginas que ya existían. Recuérdalo; aparece en entrevistas técnicas.

Operar con números

Los operadores son los símbolos que hacen cálculos. Los aritméticos son los de la calculadora, más dos nuevos:

OperadorQué haceEjemploResultado
+Suma7 + 310
-Resta7 - 34
*Multiplicación7 * 321
/División7 / 23.5
%Resto de la división entera7 % 31
**Potencia2 ** 38

El operador % (se lee «módulo» o «resto») parece raro, pero lo vas a usar muchísimo. 7 % 3 es 1 porque 7 entre 3 da 2 y sobra 1. Sirve para saber si un número es par (n % 2 da 0), para repetir cosas cada cierto número de pasos, o para convertir segundos en minutos y segundos.

El orden de las operaciones es el de las matemáticas: primero lo que está entre paréntesis, después potencias, luego multiplicaciones y divisiones, y al final sumas y restas. 2 + 3 * 4 da 14, no 20. Si dudas, usa paréntesis: (2 + 3) * 4 da 20 y no deja dudas a nadie.

Sigue este programa paso a paso. Fíjate en cómo cada línea usa los valores que calcularon las anteriores:

const precio = 120;
const cantidad = 3;
const subtotal = precio * cantidad;
const descuento = subtotal * 0.1;
const total = subtotal - descuento;
console.log("Total a pagar:", total);

Atajos para cambiar una variable

Cambiar una variable usando su propio valor es tan común que existen atajos:

let puntos = 10;
puntos += 5;   // igual que: puntos = puntos + 5   → 15
puntos -= 3;   // igual que: puntos = puntos - 3   → 12
puntos *= 2;   // igual que: puntos = puntos * 2   → 24
puntos++;      // suma 1                           → 25
puntos--;      // resta 1                          → 24

Trabajar con textos

Un texto (string) se escribe entre comillas dobles "…", simples '…' o invertidas `…`. Las dobles y las simples funcionan igual; elige unas y sé constante. Las invertidas tienen un superpoder que verás enseguida.

Plantillas literales: la forma cómoda

Unir muchas piezas con + se vuelve difícil de leer. Con comillas invertidas `…` puedes escribir el texto completo y meter valores dentro con ${…}. Esto se llama plantilla literal (en inglés, template literal):

const nombre = "Ana";
const nivel = 7;

// Con +
console.log("Hola, " + nombre + ". Estás en el nivel " + nivel + ".");

// Con plantilla literal: mismo resultado, más fácil de leer
console.log(`Hola, ${nombre}. Estás en el nivel ${nivel}.`);

// Dentro de ${} puedes poner cualquier cálculo
console.log(`El próximo nivel es el ${nivel + 1}.`);

¿Dónde está la comilla invertida?

En los teclados en español suele estar en la tecla a la derecha de la P, junto con el acento circunflejo: pulsa esa tecla y después la barra espaciadora. En Mac con teclado español es Opción + }.

Cosas útiles que puedes hacer con un texto

Los textos traen herramientas incorporadas. Se usan escribiendo un punto después del texto o de la variable:

const frase = "Aprender a programar";
console.log(frase.length);            // 20 (cantidad de caracteres, espacios incluidos)
console.log(frase.toUpperCase());     // "APRENDER A PROGRAMAR"
console.log(frase.toLowerCase());     // "aprender a programar"
console.log(frase.includes("gram"));  // true
console.log(frase.slice(0, 8));       // "Aprender" (desde la posición 0 hasta antes de la 8)
console.log("  hola  ".trim());       // "hola" (quita espacios de los extremos)

Las posiciones empiezan a contarse desde 0, no desde 1. La primera letra de frase está en la posición 0. Esto te va a acompañar en todo el curso.

Convertir entre tipos

¿Qué pasa si mezclas un número con un texto? JavaScript intenta adivinar lo que quieres y convierte uno de los dos. A eso se le llama conversión implícita, y es fuente de muchos errores. Predice cada línea antes de ejecutar:

La regla que explica casi todo: si uno de los lados del + es texto, + concatena. En cambio -, * y / solo sirven para números, así que JavaScript convierte los textos a número. En 1 + 2 + "3" primero se hace 1 + 2 = 3 (dos números), y después 3 + "3" da "33".

Suma que concatena por error

const edadTexto = "30";   // llegó de un formulario
console.log(edadTexto + 1); // "301"

Convertir primero, sumar después

const edadTexto = "30";
const edad = Number(edadTexto);
console.log(edad + 1);       // 31

Para no depender de adivinanzas, convierte tú mismo, de forma explícita:

Quieres…UsaEjemploResultado
Texto → númeroNumber(valor)Number("42.5")42.5
Texto → número enteroparseInt(valor)parseInt("42px")42
Número → textoString(valor)String(42)"42"
Algo que no es númeroNumber(valor)Number("hola")NaN

Consejo de oficio

Todo lo que escribe una persona en un formulario o en la terminal llega como texto, aunque sean números. Convertir los datos al tipo correcto justo cuando entran a tu programa evita la mayoría de estos errores. En la Estación 23: TypeScript verás una herramienta que detecta estas mezclas antes de ejecutar el código.

Resumen

  • Una variable es un nombre asociado a un valor. const crea una que no se puede reasignar; let, una que sí. Empieza con const.
  • = significa «guarda aquí», no «es igual». Primero se calcula lo de la derecha y después se guarda en la izquierda.
  • Nombres claros en camelCase: precioFinal, no x. No pueden empezar con número ni tener espacios, y distinguen mayúsculas.
  • Tipos básicos: number, string, boolean, undefined y null. typeof te dice el tipo.
  • Operadores: + - * / % **. El resto % sirve para pares e impares y para ciclos. Los decimales pueden no ser exactos: redondea con toFixed.
  • Con textos, + concatena. Las plantillas literales `…${valor}…` son más fáciles de leer.
  • Si un lado del + es texto, todo se vuelve texto. Convierte explícitamente con Number() y String().

El terreno rectangular

Semiguiado

Un terreno mide 8 metros de base y 5 de altura. Guarda esas medidas en las constantes base y altura, calcula el área (base × altura) y el perímetro (la suma de los cuatro lados), e imprime exactamente estas dos líneas:

Área: 40
Perímetro: 26
Pista

El perímetro de un rectángulo es la base dos veces más la altura dos veces: 2 * (base + altura). Guarda cada resultado en su propia constante antes de imprimirlo.

const base = 8;
const altura = 5;
const area = base * altura;
const perimetro = 2 * (base + altura);
console.log("Área: " + area);
console.log("Perímetro: " + perimetro);

Prueba a cambiar base a 10: los dos resultados se recalculan solos. Esa es la ventaja de usar variables en vez de escribir los números a mano.

Dividir la cuenta

Reto

Cuatro amigos cenan y la cuenta es de 1250.50. Quieren dejar un 15 % de propina y dividir el total en partes iguales. Imprime cuánto paga cada persona, con dos decimales: Cada persona paga: 359.52

Pista 1

El total con propina es la cuenta más el 15 % de la cuenta: cuenta + cuenta * propina, que es lo mismo que cuenta * (1 + propina).

Pista 2

Divide entre personas y usa .toFixed(2) sobre el resultado para quedarte con dos decimales.

Ver una solución 
const cuenta = 1250.50;
const propina = 0.15;
const personas = 4;
const total = cuenta * (1 + propina);
const porPersona = total / personas;
console.log("Cada persona paga: " + porPersona.toFixed(2));

Sin toFixed verías 359.51874999999995: el mismo problema de los decimales que viste antes.

Segundos a horas, minutos y segundos

Reto

Un video dura 7384 segundos. Calcula cuántas horas, minutos y segundos son e imprime 2 h 3 min 4 s. Tu programa debe funcionar si cambias 7384 por otro número.

Pista 1

Una hora tiene 3600 segundos. Math.floor(totalSegundos / 3600) te da las horas completas (Math.floor quita los decimales redondeando hacia abajo).

Pista 2

totalSegundos % 3600 son los segundos que sobran después de quitar las horas. Con esos, repite la idea usando 60 para sacar minutos y segundos.

Ver una solución 
const totalSegundos = 7384;
const horas = Math.floor(totalSegundos / 3600);
const resto = totalSegundos % 3600;
const minutos = Math.floor(resto / 60);
const segundos = resto % 60;
console.log(`${horas} h ${minutos} min ${segundos} s`);

Este patrón (dividir para sacar la parte grande y usar % para lo que sobra) aparece en relojes, temporizadores de juegos y conversiones de unidades.

Proyecto: ficha de personaje

Vas a crear la ficha de un personaje de videojuego que se imprime en la consola. Con cambiar dos o tres valores iniciales, todas las estadísticas se recalculan solas. Es el mismo principio que usan los juegos de verdad.

  1. Crea constantes para el nombre, la clase (guerrero, maga, arquero…) y el nivel del personaje.

  2. Calcula la vida máxima con la fórmula 100 + nivel * 20 y el ataque con 10 + nivel * 3.

  3. Crea una variable vidaActual que empiece igual a la vida máxima. Simula que el personaje recibe un golpe de 35 puntos (réstalos con -=).

  4. Calcula el porcentaje de vida que le queda: vidaActual / vidaMaxima * 100, redondeado sin decimales con Math.round.

  5. Imprime la ficha con plantillas literales, una línea por dato, por ejemplo:

    === LYRA · maga · nivel 7 ===
Vida: 205 / 240 (85 %)
Ataque: 31

  6. Cambia el nivel a 1 y luego a 50. Comprueba que todo se recalcula sin tocar nada más.

Ver una solución de referencia 
const nombre = "Lyra";
const clase = "maga";
const nivel = 7;

const vidaMaxima = 100 + nivel * 20;
const ataque = 10 + nivel * 3;
let vidaActual = vidaMaxima;
vidaActual -= 35;
const porcentajeVida = Math.round(vidaActual / vidaMaxima * 100);

console.log(`=== ${nombre.toUpperCase()} · ${clase} · nivel ${nivel} ===`);
console.log(`Vida: ${vidaActual} / ${vidaMaxima} (${porcentajeVida} %)`);
console.log(`Ataque: ${ataque}`);

Para ir más allá: añade defensa y velocidad con sus propias fórmulas; calcula cuántos golpes de 35 aguantaría el personaje (usa Math.ceil); o crea un segundo personaje y muestra quién tiene más ataque (lo harás con condiciones en la próxima estación).

Autoevaluación

Responde sin mirar arriba. Si fallas alguna, lee la explicación: equivocarse aquí es la forma más barata de aprender.

¿Qué hace la línea let precio = 50;?

  1. Comprueba si precio es igual a 50.

    No. Para comparar se usa ===. Un solo = asigna.

  2. Crea una variable llamada precio y le guarda el número 50.

    Correcto. let declara la variable y = le asigna el valor.

  3. Muestra el número 50 en la consola.

    No. Para mostrar algo hace falta console.log.

  4. Crea el texto «precio = 50».

    No. No hay comillas, así que no es un texto.

Después de ejecutar let x = 5; x = x + 2; x = x * 10;, ¿cuánto vale x?

  1. 5

    El 5 fue solo el valor inicial; las dos líneas siguientes lo cambian.

  2. 25

    Parece que calculaste 5 + 2 * 10. Pero son dos líneas separadas: primero x pasa a 7 y después se multiplica.

  3. 70

    Correcto: 5 + 2 = 7, y luego 7 × 10 = 70.

  4. Da error porque x aparece a los dos lados del =.

    No hay error: primero se calcula la derecha con el valor actual de x y luego se guarda.

¿Cuál de estos valores conviene guardar con const?

  1. El número de días de una semana.

    Correcto: siempre es 7, nunca se reasigna.

  2. La puntuación de un jugador durante la partida.

    Cambia cada vez que gana puntos: necesita let.

  3. Los segundos que quedan en un temporizador.

    Baja cada segundo: necesita let.

  4. La cantidad de productos en un carrito de compras.

    Cambia cuando agregas o quitas productos: necesita let.

¿Qué imprime console.log("5" + 3);?

  1. 8

    Sería 8 si los dos fueran números, pero "5" tiene comillas: es texto.

  2. 53

    Correcto. Si un lado del + es texto, + concatena: pega «5» y «3».

  3. Un error.

    JavaScript no da error: convierte el 3 a texto y concatena.

  4. NaN

    NaN aparece en operaciones matemáticas imposibles; aquí + simplemente une textos.

¿Qué imprime console.log("10" * 2);?

  1. 102

    Eso pasaría con +. El * solo sirve para números.

  2. 1010

    Multiplicar un texto no lo repite en JavaScript.

  3. 20

    Correcto. Como * solo funciona con números, JavaScript convierte "10" en 10 y multiplica.

  4. NaN

    Sería NaN si el texto no se pudiera convertir, como "diez" * 2.

¿Cuál es un nombre de variable válido y bien escrito?

  1. 2jugadores

    No puede empezar con un número.

  2. mi-nombre

    El guion se interpreta como una resta: da error.

  3. let

    Es una palabra reservada del lenguaje.

  4. nombreCompleto

    Correcto: válido y en camelCase.

¿Qué devuelve typeof "true"?

  1. "boolean"

    Ojo con las comillas: true sin comillas sería boolean.

  2. "string"

    Correcto. Entre comillas, cualquier cosa es texto.

  3. "undefined"

    El valor existe: es el texto «true».

  4. "text"

    El tipo de los textos se llama string.

¿Cuánto es 17 % 5?

  1. 3.4

    Eso es 17 / 5. El operador % da el resto.

  2. 2

    Correcto: 17 entre 5 da 3 y sobran 2.

  3. 3

    3 es el cociente (cuántas veces cabe el 5). El resto es lo que sobra.

  4. 0.17

    % no tiene que ver con porcentajes en programación.

Si const gatos = 3;, ¿qué imprime console.log(`Tengo ${gatos + 1} gatos`);?

  1. Tengo 4 gatos

    Correcto. Lo que está dentro de ${} se calcula antes de insertarse.

  2. Tengo ${gatos + 1} gatos

    Eso pasaría con comillas normales. Con comillas invertidas, ${} se evalúa.

  3. Tengo 31 gatos

    Dentro de ${}, gatos + 1 es una suma de números: 4.

  4. Un error.

    Es una plantilla literal válida.

Glosario

Variable
Nombre asociado a un valor, que permite guardarlo y usarlo después en el programa.
Declarar
Crear una variable con let o const.
Asignar
Darle un valor a una variable con el signo =.
Inicializar
Declarar una variable y asignarle su primer valor en la misma línea.
Constante
Variable creada con const: no se le puede asignar otro valor.
Tipo de dato
La clase de un valor (número, texto, booleano…), que determina qué se puede hacer con él.
String (cadena de texto)
Tipo de dato para texto. Se escribe entre comillas.
Number
Tipo de dato para números, enteros o decimales.
Boolean (booleano)
Tipo de dato con solo dos valores posibles: true (verdadero) y false (falso).
undefined
Valor de una variable que se declaró pero todavía no recibió ningún valor.
null
Valor que se usa a propósito para indicar «vacío» o «sin valor».
Operador
Símbolo que realiza una operación con valores, como +, * o %.
Módulo (resto)
Operador %: da lo que sobra al dividir dos números enteros.
Concatenar
Unir textos uno detrás de otro, por ejemplo con +.
Plantilla literal
Texto entre comillas invertidas que permite insertar valores con ${…}. En inglés, template literal.
typeof
Operador que devuelve el tipo de un valor como texto, por ejemplo "number".
NaN
Valor especial que significa «no es un número»: resulta de operaciones matemáticas sin sentido.
camelCase
Forma de escribir nombres de varias palabras juntas, con mayúscula al inicio de cada palabra nueva: precioFinal.
Palabra reservada
Palabra que el lenguaje usa para sí mismo (let, if, function…) y no puede usarse como nombre.
Conversión de tipos
Transformar un valor de un tipo a otro, de forma explícita (Number("5")) o implícita (cuando JavaScript lo hace solo).
