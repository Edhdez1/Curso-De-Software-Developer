Por qué existen los tipos

Mira estos tres datos. A simple vista se parecen mucho:

42
"42"
42.0

Para una persona, los tres significan «cuarenta y dos». Para Python son tres cosas distintas. El primero es un número entero. El segundo es un texto de dos caracteres, un 4 y un 2, igual que lo sería «ab». El tercero es un número con parte decimal. Se comportan distinto: con el primero y el tercero se puede calcular, con el segundo no.

A esa clase a la que pertenece cada dato se le llama tipo de dato (en inglés, data type). Python lo decide por cómo escribes el dato: si lleva comillas es texto, si lleva punto decimal es un decimal, y así sucesivamente. Con la función type() puedes preguntarle a Python de qué tipo es cualquier cosa:

print(type(42))
print(type("42"))
print(type(42.0))

Piensa en una aduana. Cada dato que entra a tu programa lleva un pasaporte que dice su tipo, y ese pasaporte decide qué le permiten hacer: con los enteros se puede sumar y restar, con los textos se puede unir y repetir. El límite de la analogía: una aduana humana puede hacer una excepción si le ruegas. Python no hace excepciones; si un tipo no admite una operación, se detiene con un error.

Números: int y float

Un int es un número entero: 7, -3, 1000. Un float es un número con parte decimal, que se escribe con punto: 3.14, -0.5. El nombre viene de «punto flotante» (floating point), la forma en que la computadora guarda estos números. Un número como 10.0 es float aunque no tenga decimales útiles, porque lleva el punto.

En Python puedes separar los miles con guion bajo para leer mejor: 1_000_000 es lo mismo que 1000000. Se escribe en el código, no se muestra al imprimir.

Los operadores

Un operador es un símbolo que combina datos para producir otro. Estos son los aritméticos. Los dos últimos de la lista, // y %, son nuevos para casi todo el mundo y muy útiles:

OperadorQué haceEjemploResultado

//División entera: cuántas veces cabe, sin decimales7 // 23

Hay una regla que conviene memorizar: la división / siempre devuelve un float, incluso cuando el resultado es exacto. 6 / 3 da 2.0, no 2. Y si mezclas un int con un float en una cuenta, el resultado es float: 3 + 2.0 da 5.0.

División entera y resto: horas y minutos

Una situación de todos los días: tienes 135 minutos y quieres saber cuántas horas completas son y cuántos minutos sobran. Eso es justo lo que hacen // y %.

El operador % se lee «módulo» o «resto». Sirve para convertir unidades, como acabas de ver, y para saber si un número es par: n % 2 da 0 cuando n es par y 1 cuando es impar. Lo usarás mucho cuando aprendas a tomar decisiones.

// redondea hacia abajo, hacia el número más pequeño, no hacia el cero. Por eso -7 // 2 da -4 y no -3. No pasa con frecuencia al empezar, pero es la razón por la que a veces // «da un número de más».

El orden de las operaciones es el de las matemáticas: primero lo que está entre paréntesis, luego las potencias, después multiplicaciones y divisiones, y al final sumas y restas. 2 + 3 * 4 da 14. Si dudas, usa paréntesis: (2 + 3) * 4 da 20 y no deja dudas a nadie.

Cuando los decimales no son exactos

Ejecuta esto y mira el primer resultado:

La primera línea no muestra 0.3 sino 0.30000000000000004. No es un error de Python: la computadora guarda los números en binario, y algunos decimales como 0.1 no se pueden representar exactos en binario, igual que 1/3 no se puede escribir exacto en decimal (0.3333…). Pasa en casi todos los lenguajes de programación. La solución para mostrar resultados es redondear con round(número, cuántos_decimales), que usaste en la segunda línea.

Hay otra sorpresa en ese taller. round(2.5) da 2 y round(3.5) da 4: cuando el número está justo en medio, Python redondea al par más cercano.

Un caso parecido: en Python de escritorio, round(2.675, 2) da 2.67 y no 2.68, porque 2.675 tampoco se guarda exacto: queda un poquito por debajo. Ese ejemplo no lo puedes comprobar en el taller de esta página, porque el Python del navegador es una implementación distinta y redondea ese caso de otra manera (da 2.68). Pruébalo en tu computadora. Es un recordatorio de que el Python del navegador es muy fiel, pero no idéntico. Más adelante en esta estación verás un formato (:.2f) para mostrar siempre dos decimales, que es lo que se usa al escribir importes en pantalla.

En programas que manejan dinero de verdad (tiendas, bancos), se evita usar float para guardar los importes. Se usan enteros que cuentan centavos, o un tipo especial llamado Decimal. Aquí usamos float porque estás aprendiendo lo básico; solo ten presente que la imprecisión existe.

Texto: str

Un texto (str) puede tener letras, números, signos y espacios, y se escribe entre comillas dobles "..." o simples '...'. Un texto puede estar vacío: "". Si el texto lleva comillas dentro, usa el otro tipo para envolverlo:

frase = "Ella dijo 'hola'"
otra = 'Mi libro se llama "Python"'
print(frase)
print(otra)

Para escribir un salto de línea o un tabulador dentro de un texto existen los caracteres de escape, que empiezan con una barra invertida: \n es un salto de línea y \t es un tabulador. Si necesitas textos de varias líneas, se escriben entre triples comillas """...""".

Unir y repetir

Con textos, + no suma: concatena, es decir, pega un texto detrás de otro. Y * no multiplica: repite un texto tantas veces como indique un entero.

Fíjate en las dos últimas líneas: con textos, "7" + "3" da "73" y "7" * 3 da "777". No hay cuenta matemática, aunque los textos parezcan números. Y ahora puedes entender el error de la Estación 1: "Edad: " + 25 intenta pegar un texto con un número, y Python se niega porque + entre un str y un int no tiene un significado claro. ¿Quieres que sume o que pegue? Python no adivina.

Medir y tomar caracteres

La función len() (por length, «longitud») cuenta cuántos caracteres tiene un texto, y cuenta también los espacios. Funciona con tildes y con la ñ: len("niño") es 4.

Cada carácter de un texto tiene un número de posición, llamado índice. Atención, porque es una de las cosas que más desconciertan al empezar: se empieza a contar desde 0. Para tomar un carácter, escribes el texto, y entre corchetes el índice: palabra[0]. También se puede contar desde el final con números negativos: palabra[-1] es el último.

Métodos: cambiar mayúsculas, limpiar, reemplazar

Un método es una función que «pertenece» a un dato y se llama con un punto después del dato. Los textos traen muchos; estos son los más útiles al empezar:

MétodoQué haceEjemplo
.upper()Todo en mayúsculas"hola".upper() da "HOLA"
.lower()Todo en minúsculas"HOLA".lower() da "hola"
.strip()Quita los espacios del principio y del final" hola ".strip() da "hola"
.replace(a, b)Cambia cada a por b"casa".replace("a", "o") da "coso"
.title()Cada palabra empieza con mayúscula"ana maría".title() da "Ana María"

Los textos son inmutables: una vez creados, no cambian. Los métodos no alteran el texto original, devuelven uno nuevo. Si escribes nombre.upper() y no guardas el resultado, nombre sigue igual. Guárdalo en una variable: nombre = nombre.upper(). De la misma manera, texto[0] = "X" no se permite.

Verdadero o falso: bool

Un booleano (bool) es un dato que solo puede tener dos valores: True (verdadero) o False (falso). Se llama así por George Boole, el matemático del siglo XIX que estudió la lógica con esos dos valores. En Python se escriben con la primera letra en mayúscula y sin comillas: true o "True" no son booleanos.

Casi nunca escribes un booleano a mano. Lo que produce booleanos son las comparaciones: preguntas del tipo «¿es esto mayor que aquello?» que Python responde con True o False.

OperadorPreguntaEjemploResultado
==¿Es igual?5 == 5True
!=¿Es distinto?5 != 5False
<¿Es menor?3 < 5True
>¿Es mayor?3 > 5False
<=¿Es menor o igual?5 <= 5True
>=¿Es mayor o igual?3 >= 5False

La confusión más común: edad = 18 guarda el 18 en la variable edad. En cambio edad == 18 pregunta si edad vale 18, y responde True o False. Si escribes = donde querías ==, Python no preguntará nada: guardará un valor.

Estos booleanos no hacen nada todavía por sí solos; en la próxima estación los usarás para que el programa tome decisiones con if. Por ahora quédate con que cada comparación es una expresión que vale True o False. Predice cada línea y ejecuta:

Tres detalles de ese taller. Un entero y un decimal con el mismo valor son iguales: 5 == 5.0 es True. En cambio un número y un texto nunca son iguales: 5 == "5" es False, porque son datos de tipos distintos. Y los textos se comparan carácter por carácter, según el número (el código) que la computadora le asigna a cada carácter, y en esa numeración las mayúsculas van antes que las minúsculas: por eso "Z" < "a" es True y, sobre todo, "10" < "9" también es True: compara el "1" con el "9" y no mira el resto. Para comparar números, hay que tenerlos como números.

En Python, bool es un caso especial de número: True se comporta como 1 y False como 0. Por eso True + True da 2. No necesitas usarlo, pero te servirá para entender algunos resultados del laboratorio.

None: la ausencia de un dato

Existe un valor más, de un tipo propio (NoneType): None. Significa «nada», «todavía no hay dato». Se usa para una variable que existe pero aún no tiene un valor útil, por ejemplo ganador = None antes de que termine una partida. None no es 0, ni "", ni False: es otra cosa, y por eso no se puede sumar: None + 7 da un TypeError.

Convertir de un tipo a otro

Hay veces en las que tienes un dato del tipo equivocado. El caso típico: input() te entrega el texto "25" y necesitas el número 25 para calcular. La solución es una conversión (en inglés, casting): pedirle a Python que cree un dato nuevo, de otro tipo, a partir del que tienes. Cada tipo trae su función para eso, que se llama igual que el tipo:

Fíjate en la diferencia entre los dos errores que has visto. Un TypeError dice «este tipo no admite esta operación» (sumar un texto con un número). Un ValueError dice «el tipo está bien, pero este valor no sirve» (int("abc"): es un texto, que int() sí acepta, pero ese texto no es un número).

Qué pasa con los decimales y con los booleanos

  • int(4.9) da 4: int() trunca, es decir, descarta la parte decimal sin redondear. Con negativos también descarta: int(-4.9) da -4. Si quieres redondear, usa round().
  • int("4.2") da error aunque int(4.2) funcione. Con un texto, int() solo acepta enteros. Para un texto con decimales, primero a float y luego a int: int(float("4.2")).
  • bool(x) da False para los «vacíos»: 0, 0.0, "" (texto vacío) y None. Para casi todo lo demás da True.

El texto "False" no está vacío, así que bool("False") da True. Lo mismo pasa con "0" y con un solo espacio " ". bool() mira si el dato está vacío o es cero, no lo que «dice» el texto.

Con las conversiones ya puedes arreglar el error de la Estación 1. Hay tres maneras de mostrar un texto y un número juntos; las tres funcionan:

edad = 25
print("Edad: " + str(edad))     # convertir el número a texto
print(f"Edad: {edad}")          # f-string: Python convierte solo
print("Edad:", edad)            # coma: print acepta varios datos

Dar formato a números en un texto

  
Las f-strings que conoces pueden hacer más que insertar un valor. Después de la variable, entre llaves, puedes añadir dos puntos y una instrucción de formato: {valor:formato}. Estas son las que más se usan:

  

    

      
FormatoQué haceCon x = 1234567.891

      
        
{x:.2f}Siempre dos decimales (redondea)1234567.89

        
{x:,.2f}Dos decimales y comas para separar los miles1,234,567.89

        
{x:>15.1f}Un decimal, alineado a la derecha en 15 espacios      1234567.9

        
{n:05d}Entero rellenado con ceros hasta 5 dígitos (con n = 42)00042

        
{p:.1%}Porcentaje con un decimal (con p = 0.256)25.6%

      
    

  

  
En .2f, la f indica un número con decimales en notación de «punto fijo» (fixed-point) y el .2 dice cuántos decimales mostrar. El símbolo > alinea a la derecha, < a la izquierda y ^ al centro; el número que lo sigue es el ancho total de la columna. El formato :, siempre separa los miles con coma y los decimales con punto, como se escribe en inglés (1,234.50). En español de muchos países es al revés (1.234,50). Python tiene un módulo para adaptarse a cada región, pero queda para más adelante. Por ahora, es suficiente saber que existe esa diferencia.

  






  
Resumen: lo que te llevas

  
    
    
  • Cada dato tiene un tipo y el tipo decide qué operaciones acepta. type(x) te dice cuál es.
    • 
    
  • Los tipos básicos son int (entero), float (decimal), str (texto), bool (True o False) y None (ausencia de dato). Las comillas convierten cualquier cosa en str.
    • 
    
  • La división / siempre da float. // da cuántas veces cabe y % da el resto: 135 // 60 es 2 y 135 % 60 es 15.
    • 
    
  • Los decimales no son exactos (0.1 + 0.2 da 0.30000000000000004): al mostrarlos, redondea con round() o con el formato :.2f.
    • 
    
  • Con textos, + pega y * repite. len() mide, texto[0] toma el primer carácter (se cuenta desde 0) y texto[-1] el último.
    • 
    
  • Los métodos de texto (.upper(), .strip(), .replace()) devuelven un texto nuevo; el original no cambia.
    • 
    
  • Las comparaciones (== != < > <= >=) producen booleanos. Un = guarda; un == pregunta.
    • 
    
  • Se convierte con int(), float(), str() y bool(). int(4.9) trunca a 4 y int("4.2") da error.
    • 
    
  • Un TypeError dice «este tipo no admite esta operación»; un ValueError dice «el tipo está bien, pero este valor no sirve».
    • 
    
  • Para pedir un número: int(input("...")) o float(input("...")). Para mostrarlo con formato: f"{x:.2f}".

Cambio exacto

    
Una caja tiene que entregar 463 pesos con la menor cantidad de billetes y monedas posible: billetes de 100, de 50, de 20 y de 10, y monedas de 1. Calcula cuántas piezas de cada una hacen falta y muestra, una por línea, el valor y la cantidad, así:

    
100: 4
50: 1
20: 0
10: 1
1: 3

    

      
      
    

    
Pista 1
Empieza por el billete más grande: cantidad // 100 son los billetes de 100, y cantidad % 100 es lo que queda por repartir.

    
Pista 2
Repite lo mismo con lo que queda: los billetes de 50 son resto // 50 y lo que sobra es resto % 50. Así hasta llegar a las monedas de 1, que son lo último que queda.

    
Ver una solución
      
cantidad = 463
b100 = cantidad // 100
resto = cantidad % 100
b50 = resto // 50
resto = resto % 50
b20 = resto // 20
resto = resto % 20
b10 = resto // 10
m1 = resto % 10
print(f"100: {b100}")
print(f"50: {b50}")
print(f"20: {b20}")
print(f"10: {b10}")
print(f"1: {m1}")

      
Cada paso toma lo que cabe y pasa el resto al paso siguiente. Es el mismo razonamiento que las horas y los minutos, repetido varias veces.

Glosario

  

    
Tipo de dato
La clase a la que pertenece un dato (entero, decimal, texto, booleano…). Decide qué operaciones admite.

    
Entero (int)
Número sin parte decimal, como 42 o -7.

    
Decimal (float)
Número con parte decimal, escrito con punto: 3.14. El nombre viene de «punto flotante».

    
Texto (str)
Dato formado por caracteres, siempre entre comillas. En inglés, string.

    
Booleano (bool)
Dato que solo puede ser True o False. Lleva el nombre del matemático George Boole.

    
None
Valor especial que significa «nada» o «todavía no hay dato». Tiene su propio tipo, NoneType.

    
type()
Función que dice de qué tipo es un dato.

    
Operador
Símbolo que combina datos para producir otro, como +, % o ==.

    
División entera (//)
Operación que dice cuántas veces cabe un número en otro, sin decimales. 7 // 2 es 3.

    
Resto (%)
Lo que sobra al dividir. También se llama módulo. 7 % 2 es 1.

    
Concatenar
Pegar un texto detrás de otro. En Python se hace con + entre textos.

    
Índice
Número de posición de un carácter dentro de un texto. Se cuenta desde 0; con negativos se cuenta desde el final.

    
len()
Función que cuenta los caracteres de un texto, incluidos los espacios.

    
Método
Función que pertenece a un dato y se llama con un punto después de él, como "hola".upper().

    
Inmutable
Que no se puede modificar una vez creado. Los textos lo son: sus métodos devuelven un texto nuevo.

    
Carácter de escape
Secuencia que empieza con barra invertida y representa un carácter especial dentro de un texto, como \n (salto de línea).

    
Comparación
Operación que pregunta algo sobre dos datos (¿son iguales?, ¿es mayor?) y responde con un booleano.

    
Conversión (casting)
Crear un dato nuevo de otro tipo a partir de uno existente, con int(), float(), str() o bool().

    
Truncar
Descartar la parte decimal de un número sin redondear. int(4.9) da 4.

    
TypeError
Error que aparece cuando un tipo de dato no admite la operación pedida, como sumar un texto con un número.

    
ValueError
Error que aparece cuando el tipo es correcto pero el valor no sirve, como int("abc").

    
IndexError
Error que aparece cuando pides una posición de un texto que no existe.

    
ZeroDivisionError
Error que aparece al dividir entre cero.

    
Formato de una f-string
Instrucción que se escribe después de dos puntos dentro de las llaves, como {x:.2f}, para controlar cómo se muestra un valor.
