Glosario

20 términos del curso explicados con palabras sencillas. Cada uno enlaza con la estación donde se enseña a fondo.

ABCDIMNOPSTUV

A

Asignar
Darle un valor a una variable con el signo =. 2Variables

B

Boolean (booleano)
Tipo de dato con solo dos valores posibles: true (verdadero) y false (falso). 2Variables

C

camelCase
Forma de escribir nombres de varias palabras juntas, con mayúscula al inicio de cada palabra nueva: precioFinal. 2Variables
Concatenar
Unir textos uno detrás de otro, por ejemplo con +. 2Variables
Constante
Variable creada con const: no se le puede asignar otro valor. 2Variables
Conversión de tipos
Transformar un valor de un tipo a otro, de forma explícita (Number("5")) o implícita (cuando JavaScript lo hace solo). 2Variables

D

Declarar
Crear una variable con let o const. 2Variables

I

Inicializar
Declarar una variable y asignarle su primer valor en la misma línea. 2Variables

M

Módulo (resto)
Operador %: da lo que sobra al dividir dos números enteros. 2Variables

N

NaN
Valor especial que significa «no es un número»: resulta de operaciones matemáticas sin sentido. 2Variables
null
Valor que se usa a propósito para indicar «vacío» o «sin valor». 2Variables
Number
Tipo de dato para números, enteros o decimales. 2Variables

O

Operador
Símbolo que realiza una operación con valores, como +, * o %. 2Variables

P

Palabra reservada
Palabra que el lenguaje usa para sí mismo (let, if, function…) y no puede usarse como nombre. 2Variables
Plantilla literal
Texto entre comillas invertidas que permite insertar valores con ${…}. En inglés, template literal. 2Variables

S

String (cadena de texto)
Tipo de dato para texto. Se escribe entre comillas. 2Variables

T

Tipo de dato
La clase de un valor (número, texto, booleano…), que determina qué se puede hacer con él. 2Variables
typeof
Operador que devuelve el tipo de un valor como texto, por ejemplo "number". 2Variables

U

undefined
Valor de una variable que se declaró pero todavía no recibió ningún valor. 2Variables

V

Variable
Nombre asociado a un valor, que permite guardarlo y usarlo después en el programa. 2Variables
