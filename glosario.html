B

Booleano (bool)
Dato que solo puede ser True o False. Lleva el nombre del matemático George Boole. 1Tipos de datos

C

Cadena de texto (string)
Dato que es texto. En Python se escribe entre comillas. 1Tu primer programa
Carácter de escape
Secuencia que empieza con barra invertida y representa un carácter especial dentro de un texto, como \n (salto de línea). 1Tipos de datos
Carpeta (directorio)
Lugar de la computadora donde se guardan archivos y otras carpetas. 1Tu primer programa
Comando
Orden escrita que le das a la terminal, como ls o cd. 1Tu primer programa
Comentario
Nota para personas dentro del código. En Python empieza con # y el intérprete la ignora. 1Tu primer programa
Comparación
Operación que pregunta algo sobre dos datos (¿son iguales?, ¿es mayor?) y responde con un booleano. 1Tipos de datos
Concatenar
Pegar un texto detrás de otro. En Python se hace con + entre textos. 1Tipos de datos
Conversión (casting)
Crear un dato nuevo de otro tipo a partir de uno existente, con int(), float(), str() o bool(). 1Tipos de datos

D

Decimal (float)
Número con parte decimal, escrito con punto: 3.14. El nombre viene de «punto flotante». 1Tipos de datos
División entera (//)
Operación que dice cuántas veces cabe un número en otro, sin decimales. 7 // 2 es 3. 1Tipos de datos

E

Editor de código
Programa para escribir texto simple que además colorea el código y ayuda a escribirlo. Visual Studio Code es uno. 1Tu primer programa
Ejecutar
Hacer que la computadora cumpla las instrucciones de un programa. 1Tu primer programa
Entero (int)
Número sin parte decimal, como 42 o -7. 1Tipos de datos
Error de sintaxis (SyntaxError)
Error que aparece cuando una línea rompe las reglas de escritura del lenguaje, como unas comillas sin cerrar. Se detecta antes de ejecutar. 1Tu primer programa
Extensión de archivo
Las letras después del punto en el nombre de un archivo, que indican su tipo. Los programas de Python terminan en .py. 1Tu primer programa
Extensión de VS Code
Complemento que añade funciones al editor, como entender Python. 1Tu primer programa

F

f-string
Texto con una f antes de las comillas que permite insertar variables o cálculos entre llaves {}. 1Tu primer programa
Formato de una f-string
Instrucción que se escribe después de dos puntos dentro de las llaves, como {x:.2f}, para controlar cómo se muestra un valor. 1Tipos de datos
Función
Instrucción ya preparada, con nombre, que puedes usar escribiendo su nombre y paréntesis. print es una. 1Tu primer programa

I

IndexError
Error que aparece cuando pides una posición de un texto que no existe. 1Tipos de datos
Índice
Número de posición de un carácter dentro de un texto. Se cuenta desde 0; con negativos se cuenta desde el final. 1Tipos de datos
Inmutable
Que no se puede modificar una vez creado. Los textos lo son: sus métodos devuelven un texto nuevo. 1Tipos de datos
input()
Función que pausa el programa, muestra una pregunta y devuelve como texto lo que la persona escribe. 1Tu primer programa
Intérprete
Programa que lee tu código línea por línea y lo ejecuta. Al instalar Python se instala su intérprete. 1Tu primer programa

L

len()
Función que cuenta los caracteres de un texto, incluidos los espacios. 1Tipos de datos
Lenguaje de programación
Idioma con reglas estrictas en el que se escriben las instrucciones de un programa. 1Tu primer programa

M

Método
Función que pertenece a un dato y se llama con un punto después de él, como "hola".upper(). 1Tipos de datos

N

NameError
Error que aparece cuando usas un nombre que Python no conoce: una variable o función mal escrita o sin crear. 1Tu primer programa
None
Valor especial que significa «nada» o «todavía no hay dato». Tiene su propio tipo, NoneType. 1Tipos de datos

O

Operador
Símbolo que combina datos para producir otro, como +, % o ==. 1Tipos de datos

P

Programa
Lista de instrucciones que una computadora cumple en orden para hacer una tarea. 1Tu primer programa
Prompt
La marca que muestra la terminal para indicar que espera un comando. En esta página se representa con $. 1Tu primer programa
Python
Lenguaje de programación creado por Guido van Rossum, publicado en 1991. Se lee casi como una frase y se usa en muchos campos. 1Tu primer programa

R

Resto (%)
Lo que sobra al dividir. También se llama módulo. 7 % 2 es 1. 1Tipos de datos

S

Sangría (indentación)
Espacios al principio de una línea. En Python tienen significado, por eso una sangría de más da error. 1Tu primer programa

T

Terminal
Ventana donde das órdenes a la computadora escribiéndolas. También se llama consola. 1Tu primer programa
Texto (str)
Dato formado por caracteres, siempre entre comillas. En inglés, string. 1Tipos de datos
Tipo de dato
La clase a la que pertenece un dato (entero, decimal, texto, booleano…). Decide qué operaciones admite. 1Tipos de datos
Traceback
Mensaje de error de Python que muestra el recorrido hasta el problema: el archivo, la línea y qué pasó. 1Tu primer programa
Truncar
Descartar la parte decimal de un número sin redondear. int(4.9) da 4. 1Tipos de datos
type()
Función que dice de qué tipo es un dato. 1Tipos de datos
TypeError
Error que aparece cuando un tipo de dato no admite la operación pedida, como sumar un texto con un número. 1Tipos de datos

V

ValueError
Error que aparece cuando el tipo es correcto pero el valor no sirve, como int("abc"). 1Tipos de datos
Variable
Nombre que le das a un dato para poder usarlo después. Se crea con =. 1Tu primer programa

Z

ZeroDivisionError
Error que aparece al dividir entre cero. 1Tipos de datos
