## 📁 Estructura de Estaciones

Cada línea contiene 5 estaciones con progresión clara:

### Ejemplo: Línea 1 (Python Fundamentos)
- **Estación 1:** Tu Primer Programa (instalación, Hello World, print)
- **Estación 2:** Tipos de Datos (int, float, str, bool, conversión)
- **Estación 3:** Control de Flujo (if/elif/else, comparaciones)
- **Estación 4:** Bucles (for, while, range, break)
- **Estación 5:** Proyecto Gestor de Tareas (integración)

### Ejemplo: Línea 5 (GUIs y Vault v1)
- **Estación 21:** Introducción a Tkinter (ventanas, botones, labels)
- **Estación 22:** Layouts (grid, pack, place)
- **Estación 23:** Manejo de Archivos (diálogos, lectura/escritura)
- **Estación 24:** Templates con Jinja2
- **Estación 25-26:** Proyecto Vault Académico v1 (completo)

## 🏗️ Proyecto Integrador: Vault Académico + Portafolio Digital

Un **proyecto real** que evoluciona a través de 3 fases:

### Fase 1: Vault v1 (Línea 5) - Python Local
**Tecnologías:** Python 3.11+, SQLite, Tkinter, Jinja2  
**Funcionalidades:**
- Organizar documentos académicos en categorías
- Generar portafolio HTML exportable
- Interfaz gráfica completa
- Base de datos local

**Mercado:** Estudiantes que necesitan portafolios

---

### Fase 2: Backend API (Línea 7) - Node.js
**Tecnologías:** Node.js, Express, MongoDB/PostgreSQL, JWT  
**Funcionalidades:**
- API REST profesional para documentos
- Autenticación de usuarios
- Generación dinámica de portafolios
- Testing completo

**Mercado:** Instituciones educativas, plataformas de empleo

---

### Fase 3: Vault v2 (Línea 9) - App Multiplataforma
**Tecnologías:** .NET MAUI, C#, Firebase, XAML  
**Funcionalidades:**
- App nativa para iOS, Android, Windows
- Sincronización en nube (Firebase)
- Portafolio exportable a PDF
- Compartir documentos verificables
- Publicada en App Store / Google Play

**Mercado:** Profesionales globales, estudiantes internacionales

## 💡 ¿Por qué este Curriculum?

### 1. Progresión Lógica
- **Python primero:** Simplifica conceptos, construyes intuición
- **JavaScript después:** Entiende async/concurrencia
- **C# al final:** Tipado fuerte, arquitecturas robustas
- **Opcional:** C, Rust, Go para especialización

### 2. Un Proyecto Real
- **No ejercicios abstractos:** Construyes Vault desde cero
- **Portfolio real:** Publicable en GitHub, App Stores
- **Ayuda a otros:** Resuelve problema real (portafolios académicos)
- **Evoluciona:** Cada línea añade features y complejidad

### 3. Empleo
- **Línea 8:** Job-ready como Junior
- **Línea 9:** Senior/Arquitecto
- **Portfolio:** Demuestras capacidad real (no solo certificados)

### 4. Flexible
- **Líneas 10-11 opcionales:** No todos necesitan juegos/sistemas
- **Enfoque:** Elige especialidad (web, mobile, games, backend)
- **Ritmo:** 36h/semana = 6 meses, o escala a tu velocidad
